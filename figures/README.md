# Figures and Visualisations

This folder contains the figures produced for the systematic review, *Optimal Delivery of Multimodal Prehabilitation for Adults Undergoing Major Cancer Surgery*.

The figures summarise the characteristics of included studies, intervention components, outcome reporting, study size and attrition, study selection, and risk-of-bias assessments.

## Python-Generated Visualisations

The following figures were generated using the Python scripts in the /scripts folder:

- Evidence map
- Evidence map bubble chart
- Intervention duration
- Intervention frequency
- Outcome effects
- Sample size and dropouts

## PRISMA Flow Diagram

The PRISMA flow diagram documents the study-selection process, including records identified, screened, excluded and included in the review.

It was created manually in Microsoft Word using the final study-selection data from the systematic review and then exported as an image for inclusion in this folder.

## Risk-of-Bias Visualisation

The RoB 2 traffic-light plot presents the risk-of-bias assessment for the primary outcome of each included study. Assessments were conducted using the Cochrane Risk of Bias 2 (RoB 2) tool across the following domains:

1. Bias arising from the randomisation process  
2. Bias due to deviations from intended interventions  
3. Bias due to missing outcome data  
4. Bias in measurement of the outcome  
5. Bias in selection of the reported result  

Each study was judged as having low risk of bias, some concerns, or high risk of bias.

The traffic-light figure was generated using the online **robvis** (Risk-of-bias VISualization) tool. To reproduce it:

1. Open the robvis web-based visualisation tool (https://www.riskofbias.info/welcome/robvis-visualization-tool)
2. Select assessment tool template RoB 2.0
3. Upload the completed RoB 2 Excel file (risk_of_bias_rob2.xlsx) from the /data folder
4. Generate and export the figure.
